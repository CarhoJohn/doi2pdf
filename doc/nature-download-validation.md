# Nature 备用下载验证记录

日期：2026-10-06。Windows；Zotero 10.0.5；doi2pdf 0.1.3。
所有 Zotero 写入均在独立 profile 和数据目录内进行，测试收藏夹名称为 `api测试`。

## 测速

先使用命令行 curl 8.9.1，分别建立独立 Cookie 文件，连续测量三次。
DOI 为 `10.1038/s42256-026-01281-1`；文章页和 PDF 均返回 HTTP 200，
PDF 响应类型为 `application/pdf`。

| 样本 | 文章页（秒） | PDF（秒） | 两次请求合计（秒） |
| ---- | -----------: | --------: | -----------------: |
| 1    |        3.006 |     2.360 |              5.367 |
| 2    |        3.423 |     1.811 |              5.234 |
| 3    |        3.332 |     2.367 |              5.698 |

再运行插件构建代码，由插件通过 Gecko Subprocess 直接启动 Windows 系统目录中的
curl.exe 8.21.0。此处总时间包括进程启动、网页解析与 PDF 校验，不含附件入库。

| DOI                          | 文章页（秒） | PDF（秒） | 备用流程总时间（秒） | 结果                                  |
| ---------------------------- | -----------: | --------: | -------------------: | ------------------------------------- |
| `10.1038/s42256-026-01281-1` |        3.987 |     3.398 |                7.571 | 原父条目下保存 1,901,103 字节 PDF     |
| `10.1038/s41562-026-02563-9` |        3.373 |     2.953 |                6.370 | 真实 HTTP API 返回 `found` / `nature` |

第二条通过独立实例的 `POST /api/plus/add-doi` 测试，使用原生写入认证头。
原生获取等待 15 秒后触发备用流程；整个 HTTP 请求耗时 24.729 秒。
此时父条目的元数据已存在，因此该测量不包含新条目的元数据检索。

作为对照，先前 Zotero.HTTP 的一次较长超时诊断在文章页阶段运行 48.481 秒后
报告连接失败，没有取得 PDF。这里只记录本机结果，不据此判断具体网络原因。

目前这些 curl 测量支持保留 20 秒总预算。网络和访问权限变化仍可能导致失败。
成功结果会返回 `fullText.timings.articleMs`、`pdfMs`、`totalMs`，可继续积累样本。

## 已完成验证

- 真实插件调用系统 curl 下载并保存到正确父条目；重复调用复用同一 PDF 附件。
- `add-doi` 传入本地 PDF 后直接导入，保留原文件。
- `import-pdf` 复用已有附件，并拒绝父条目 DOI 不匹配的请求。
- 真实元数据检索及并发调用只创建一个父条目，元数据阶段不下载附件。
- 在独立测试构建中给 curl 注入每秒 1 字节的限速，原生等待 15 秒后启动备用下载，
  整体在 35.021 秒返回 20 秒超时；父条目没有新增附件，随后检查无残留 curl
  子进程或 Nature 临时目录。正式 XPI 不含这个限速参数。
- 15 项离线回归测试涵盖原生成功、提前失败、15 秒触发、晚到结果、20 秒终止、
  进程启动晚于超时、HTML 伪 PDF、DOI 不匹配、错误 URL、缺少 curl 和 curl HTTP 错误。
- TypeScript 检查、构建、格式和 ESLint 检查通过。

原始 JSON 记录位于本地忽略目录 `.scaffold/diagnostics/nature-curl-timings.json`、
`.scaffold/pdf-validation/nature-curl-result.json` 和
`.scaffold/pdf-validation/nature-curl-http-result.json`。
限速超时测试记录在 `.scaffold/pdf-validation/nature-curl-timeout-result.json`。
本报告不包含 Cookie 或 API key。其他操作系统未进行真实运行验证。
